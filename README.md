# WaveSync — Совместное прослушивание музыки в оригинальном качестве

Веб-приложение для синхронного прослушивания аудиофайлов с устройства (как Watch2Gether, только для аудио и без пережатия звука).

## Как это работает
1. **100% оригинальное качество звука:** файлы с устройства хоста (`FLAC`, `WAV`, `MP3`, `M4A`, `OGG`, `OPUS`, `AAC`) передаются слушателям байт-в-байт через **WebRTC DataChannel** (надёжный канал данных, а не голосовой поток). Воспроизведение идёт нативно через `<audio>` без перекодирования.
2. **Бесплатно без сервера хранения:** файлы не загружаются на платные облачные диски — передача идёт напрямую между браузерами участников.
3. **Синхронизация через Firebase RTDB:** комнаты по 4-значному коду, список слушателей, очередь и единое серверное время (`.info/serverTimeOffset`) с мягкой подстройкой дрифта (`0.97x / 1.03x` и `preservesPitch`).
4. **Роли:**
   - **Хост:** создаёт комнату, добавляет треки с устройства, управляет плейлистом, перемоткой, паузой и режимом повтора.
   - **Слушатель:** подключается по 4-значному коду или ссылке `?room=XXXX`, видит лобби и очередь, слушает трек синхронно со своей локальной громкостью.

## Локальный запуск
```bash
npm install
npm run dev
```

## Тесты и сборка
```bash
npm test
npm run build
```

## Переменные окружения (опционально)
По умолчанию используются Firebase RTDB и бесплатные STUN-серверы (Google / Cloudflare). При желании можно переопределить через `.env`:
- `VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_DATABASE_URL`, и т.д.
- `VITE_TURN_URL`, `VITE_TURN_USER`, `VITE_TURN_PASS` (или указать TURN прямо в интерфейсе в разделе **Сеть / TURN**, если два мобильных оператора блокируют прямое P2P-соединение).
